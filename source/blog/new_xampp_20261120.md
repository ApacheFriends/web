Hi Apache Friends!

We just released a new version of XAMPP for Windows, Linux and macOS with PHP versions 8.3.37, 8.4.28, 8.5.13. You can download these new installers at [http://www.apachefriends.org/download.html](/download.html).

These installers include the following main components:

- PHP 8.3.37, 8.4.28, 8.5.13
- Apache 2.4.71
- MariaDB 10.11.19
- phpMyAdmin 5.2.3
- OpenSSL 3.6.5

Just a reminder that you can also contribute to the project at any time! All the code and resources are available at the [GitHub Apache Friends](https://github.com/ApacheFriends) project.
